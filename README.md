### 🥒 [Cucumber Growth Stage Classification](https://github.com/Mallikarjuna722005/Research)
*Plant growth-stage classification using deep transfer learning.*

![Python](https://img.shields.io/badge/Python-3776AB?style=flat-square&logo=python&logoColor=white)
![TensorFlow](https://img.shields.io/badge/TensorFlow-FF6F00?style=flat-square&logo=tensorflow&logoColor=white)
![OpenCV](https://img.shields.io/badge/OpenCV-5C3EE8?style=flat-square&logo=opencv&logoColor=white)

- **Classes:** flowering, pollination, mature, ripen, overripen
- **Data:** smartphone images under varied lighting, angles and occlusion
- **Pipeline:** 224×224 resizing; augmentation (rotation, flipping, zoom, brightness, blur)
- **Models:** EfficientNetV2, ResNet50 and VGG16 feature extractors with a softmax head
- **Evaluation:** accuracy, precision, recall, F1 and confusion matrix

*Status: architecture documented; notebooks and results in progress.*
